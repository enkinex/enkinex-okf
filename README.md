# Enkinex OKF — Open Knowledge Format (OKF) as Code Library

[![Standard](https://img.shields.io/badge/OKF-v0.1-blue)](https://github.com/bitol-io/open-data-contract-standard/tree/v3.1.0)
[![KCL](https://img.shields.io/badge/KCL-%E2%89%A5%200.12.4-7B68EE)](https://www.kcl-lang.io/)
[![Version](https://img.shields.io/badge/version-v0.1-orange)](./CHANGELOG.md)
[![License](https://img.shields.io/badge/license-Apache--2.0-green)](./LICENSE)

> A modular [KCL](https://www.kcl-lang.io/) library for the
> [Open Knowledge Format (OKF) v0.1](https://github.com/GoogleCloudPlatform/knowledge-catalog/tree/main/okf),
> built to author, type-check, and validate the Open Knowledge Format v0.1 draft specification.

## Project Summary

"OKF is a universal, vendor-neutral format for representing knowledge as plain Markdown files with YAML frontmatter. It is not tied to any particular agent, framework, model provider, or serving system."
